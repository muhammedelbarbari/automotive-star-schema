# 🚗 Automotive Star Schema – Data Modeling Project

## 📌 Overview
This project demonstrates the design of an **Automotive Star Schema** used for analytics and reporting.  
The goal is to organize automotive-related data into a clean dimensional model that supports fast querying and business insights.

---

## ⭐ Star Schema Structure

### 🟦 Fact Table
- **Fact_Sales**  
  Contains transactional automotive sales data including revenue, quantity, and date keys.

### 🟩 Dimension Tables
- **Dim_Customer** – customer demographics  
- **Dim_Car** – car model, brand, category  
- **Dim_Dealer** – dealership information  
- **Dim_Date** – calendar attributes  
- **Dim_Location** – city, region, country  

---

## 🎯 Project Objectives
- Build a clean dimensional model for automotive analytics  
- Improve query performance using star schema design  
- Enable insights such as:  
  - Top-selling car models  
  - Revenue by region  
  - Dealer performance  
  - Customer segmentation
